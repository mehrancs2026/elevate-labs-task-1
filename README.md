# NEXORA — Responsive Landing Page

A modern and responsive landing page built using HTML5 and CSS3 as part of Task 1 of the Elevate Labs Web Development Internship.

## 🌐 Live Demo

https://mehrancs2026.github.io/elevate-labs-task-1/

## 📌 Project Overview

NEXORA is a fictional technology brand focused on innovation, creativity and meaningful digital experiences.

The landing page features a clean layout, modern typography and a dark navy and electric blue colour scheme.

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action button
- About section
- Footer with social links
- Flexbox-based layouts
- Mobile responsive design
- CSS hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- GitHub Pages

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📱 Responsive Design

The website uses CSS media queries to adapt its layout to smaller screens and mobile devices.
